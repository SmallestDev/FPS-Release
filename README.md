# Five Pieces of Stones

First public release of **Five Pieces of Stones**.

## Version
**v1.0.0**

## Download
Download `FPS.zip`, extract the ZIP file, and run `FPS.exe`.

## Updates
The game includes an automatic update system.

When a new version is released, the game will check for updates when launched and download the latest version automatically.

## Installation
1. Download `FPS.zip`
2. Extract all files
3. Run `FPS.exe`

> Do not run the game directly inside the ZIP file. Extract it first.

## Notes
This is an early release, so bugs or unexpected issues may occur.

If you encounter a problem, please report it so it can be fixed in a future update.
